# CustomerPulse — Customer Revenue & Retention Analytics

CustomerPulse is a portfolio-focused data analytics project that transforms raw e-commerce transaction data into customer, revenue, and retention insights using Python and RFM (Recency, Frequency, Monetary) analysis.

## Business Problem

An e-commerce business has thousands of transaction records, but raw sales data does not directly answer the questions management cares about:

- Who are the most valuable customers?
- Which customers purchase repeatedly?
- Which customers appear to be becoming inactive?
- How concentrated is revenue among customers?
- Which products and countries drive revenue?
- Where should retention efforts be focused?

CustomerPulse answers these questions through reproducible data cleaning, KPI analysis, customer-level feature engineering, RFM segmentation, visual analysis, and business recommendations.

## Dataset

**UCI Machine Learning Repository — Online Retail**

The dataset contains 541,909 transaction records from a UK-based non-store online retailer covering transactions between 1 December 2010 and 9 December 2011.

Main fields:

| Field | Description |
|---|---|
| InvoiceNo | Transaction / invoice identifier |
| StockCode | Product identifier |
| Description | Product description |
| Quantity | Units purchased |
| InvoiceDate | Transaction timestamp |
| UnitPrice | Price per unit |
| CustomerID | Customer identifier |
| Country | Customer country |

Dataset source: https://archive.ics.uci.edu/dataset/352/online+retail

## RFM Analysis

Each customer will be represented using:

- **Recency:** Number of days since the customer's most recent purchase.
- **Frequency:** Number of unique purchases made by the customer.
- **Monetary:** Total revenue generated by the customer.

Customers will then be grouped into business-friendly segments such as:

- Champions
- Loyal Customers
- Potential Loyalists
- Needs Attention
- At Risk
- Lost / Hibernating

The segmentation rules will be documented clearly so the analysis remains reproducible and explainable.

## Planned Analysis

### 1. Data Quality & Cleaning
- Inspect data types and missing values
- Remove invalid Customer IDs where customer-level analysis requires them
- Identify duplicate records
- Identify cancelled invoices
- Remove or separately analyze non-positive quantities / invalid prices
- Create a `Revenue = Quantity × UnitPrice` feature

### 2. Executive KPI Analysis
- Revenue
- Orders
- Customers
- AOV
- Repeat purchase rate
- Revenue per customer

### 3. Revenue & Transaction Analysis
- Monthly revenue trend
- Monthly order trend
- Revenue by country
- Top products by revenue
- Top customers by revenue
- Revenue concentration

### 4. Customer Behaviour Analysis
- Orders per customer
- Spend per customer
- Repeat vs one-time customers
- Purchase recency
- Customer value distribution

### 5. RFM Customer Segmentation
- Calculate Recency, Frequency and Monetary values
- Convert RFM metrics to scores
- Assign interpretable customer segments
- Compare segment size and revenue contribution

### 6. Business Insights
The final analysis will frame findings as:

**Observation → Why it matters → Recommended action**

Examples:
- High-value customers generating a disproportionate share of revenue
- Previously valuable customers showing high recency values
- Large one-time-buyer population indicating retention opportunity
- Geographic markets contributing strongly to revenue
